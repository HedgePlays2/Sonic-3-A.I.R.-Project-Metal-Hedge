# Metal Hedge — Locked Visual Concept

The green Metal Hedge concept is approved as the current visual direction for Project Metal Hedge.

## Design direction
- Emerald and bright green armor as the primary color scheme
- Red shoes retained from the Metal Sonic reference
- Gold/yellow accents and white metallic highlights
- Dark outlines and high-contrast 16-bit Sonic-style shading
- Preserve the boss-fight concept: idle/movement poses, attacks, effects, and defeated pose

## Status
This is a **visual concept reference**, not a game-ready sprite sheet. The generated concept image does not preserve the original sprite sheet pixel-for-pixel, so it must not be used as a drop-in game asset. The next asset step is to recolor the original sprite sheet while preserving its exact dimensions, frame positions, transparency, and animation layout.
