# Sprite Mod Assets

This folder is reserved for Sonic 3 A.I.R. sprite overrides.

## Planned use
- Prepare a Metal Hedge version of the Metal Sonic sprite sheet.
- Preserve pixel-art dimensions, palette shading, and transparent pixels.
- Add the matching Sonic 3 A.I.R. sprite definition JSON files when the exact target sprite is identified.

Do not drop the source PNGs here as overrides until the expected game paths and companion JSON files have been confirmed. The source sheets in the repository root remain untouched.
